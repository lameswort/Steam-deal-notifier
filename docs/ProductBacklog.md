# Steam Deal Notifier - Product Backlog
The following user stores outline the planned features for the application, ordered by priority.
| Product Backlog ID | Requirement | User Story | Priority |
|---|---|---|---|
| PB-01 | FR-01 Steam Wishlist Integration | US-01 Connect Steam account | High |
| PB-02 | FR-01 Steam Wishlist Integration | US-02 View wishlist games | High |
| PB-03 | FR-02 Sale Detection | US-03 View discounted games | High |
| PB-04 | FR-03 Price History Tracking | US-04 View historical prices | High |
| PB-05 | FR-04 Deal Quality Analysis | US-05 View deal quality rating | High |
| PB-06 | FR-05 Sale Notifications | US-06 Receive sale notifications | High |
| PB-07 | FR-02 Sale Detection | US-07 Refresh game prices | Medium |
| PB-08 | NFR-02 Reliability | US-08 View error messages | Medium |

## Story Points and Acceptance Criteria

| User Story | Story Points | Acceptance Criteria |
|---|---|---|
| US-01 | 3 | Users can enter a Steam account identifier. |
| US-02 | 5 | Accessible wishlist games are displayed. |
| US-03 | 5 | Discounted games display prices and discount percentages. |
| US-04 | 8 | Historical prices and the lowest recorded price are displayed when available. |
| US-05 | 5 | Current prices are compared with historical data to produce a deal rating. |
| US-06 | 5 | Users receive notifications containing game and sale information without duplicate alerts for unchanged sales. |
| US-07 | 3 | Users can manually refresh game prices. |
| US-08 | 3 | API failures display error messages without crashing the application. |
