# US-01: Monitor sales
As a Steam User, I want to monitor sales so that I can spend my money wisely.
- The application shall monitor the prices of games on the users wishlist.
- The application shall detect when a game goes on sale.
- The application shall notify the user of the sale price.

# US-02: Tracking List
As a Steam User, I want a tracking list so that monitoring sales is easy and efficient.
- The application shall allow users to add games to their tracking list.
- The application shall display all games on the tracking list.
- The application shall prevent the same game from being added more than once.

# US-03: Remove games from tracking list
As a Steam User, I want to be able to remove games from said tracking list so that if I become uninterested in a game I can remove it.
- The application shall let users remove games from their tracking list.
- The game will no longer appear in the tracking list.
- The application will stop monitoring the removed game.

# US-04: View Current Discount Percentages
As a Steam user, I want to view the current discount percentage of games on my wishlist so I can see how much money I am saving. 
- The application displays the current discount percentage for games on sale.
- The application displays the original and discounted prices.
- Games that are not on sale display their regular prices.

# US-05: View Historical Game Prices 
As a Steam user, I want to view past sales for games, so I can see how their prices have changed over time.
- The application will retrieve historical price data.
- The application shall display previous prices and dates.
- The application shall display an error if pricing is not available

# US-06: Compare Current Prices with with Previous Sales
As a Steam user, I want to compare current game prices with their previous ones, so that i can figure out if the current discount is better than the past discounts. 
- The application shall display the current price of a game alongside available previous sale prices
- The application shall identify the lowest price available in price history.
- The application will indicate whether the sale is good relative to previous sales.

# US-07: Identify Whether a Sale Is a Good Deal
As a Steam user, I want to know whether the current discount is good, so that I can decide to purchase now or wait for another sale.
- The application shall determine if the sale is a good deal based on predefined comparison rules.
- The application shall display a recommendation on whether the user should buy or not
- The application shall display when not enough data is available to make a decision.

# US-08: View Sale Frequency 
As a Steam user, I want to know how often a game goes on sale, so that i can decide to purchase the game now or wait for another sale.
- The application shall retrieve historical sale information
- The application shall display the number of times a sale has occurred.
- The application shall indicate when there is not enough sale data.

# US-09: Search for Games in the Tracking List
As a Steam user, I want to search for games in my tracking list, so that I can quickly find a certain game.
- The application shall provide a search field to search games with.
- The application shall display games entered in the search query
- The search shall not be case sensitive.

# US-10: Receive an Error Message When Game Data Is Unavailable 
As a Steam user, I want to be notified when game information cannot be retrieved, so that I know when information isn’t available.
- The application shall detect when a requested game information cannot be retrieved
- The application shall display a clear error message.
- The application will handle errors without crashing or freezing.
